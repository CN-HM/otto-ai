推荐填写方式

新建知识库后进入内容管理页面上传资料，系统会自动解析、切块、使用平台默认向量模型生成向量并写入检索库。

向量模型如何管理？

请在“绑定配置中心 > Embedding Profile”新增模型并绑定云平台 Integration，可维护多个模型和默认模型。

内容维护建议

建议按业务主题拆分知识库，例如产品 FAQ、售后政策、设备说明书，避免一个知识库混入过多无关主题。
